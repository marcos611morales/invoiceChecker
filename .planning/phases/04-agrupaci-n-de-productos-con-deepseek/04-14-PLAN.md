## Phase Goal

**As a** dueño, socio o contador del Coworking Café, **I want to** pedir a DeepSeek que agrupe como "mismo producto" los conceptos con descripciones distintas entre tiendas y que sugiera categorías, revisando cada sugerencia antes de aplicarla, **so that** nada cambia sin mi revisión y a DeepSeek solo llegan descripciones de conceptos y nombres de proveedor, por una ruta protegida.

<objective>
Let DeepSeek add new descriptions to products the user already has: the names of the accepted products go as context on every request (D-04, D-33), and groups placed with an accepted product become «Agregar a «X»» cards (D-21).

Purpose: without context every new invoice upload would create duplicates of products the user already curated. D-33 (answered by the user on 2026-10-19, the former option-a) fixes which names travel: accepted names always, earlier-batch names inside one run (Plan 04-15), never the names of pending cards from earlier runs. Nothing is gated: the decision is locked.
Output: accepted-name context on the bodies and the target map, `addMembersToProduct`, the context lines of the dialog and the «Agregar a» card.
</objective>
