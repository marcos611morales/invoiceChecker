## Phase Goal

**As a** dueño, socio o contador del Coworking Café, **I want to** pedir a DeepSeek que agrupe como "mismo producto" los conceptos con descripciones distintas entre tiendas y que sugiera categorías, revisando cada sugerencia antes de aplicarla, **so that** nada cambia sin mi revisión y a DeepSeek solo llegan descripciones de conceptos y nombres de proveedor, por una ruta protegida.

<objective>
Let similar descriptions in different batches of one long run end up in the same product (D-28) under the rule the user chose (D-33): each later batch carries the names DeepSeek proposed in the earlier batches of that run, and a description placed with one of those cards joins it, becomes an «Agregar a» card if the user already accepted it, or keeps its own card if the user rejected it.

Purpose: D-33 locks this behavior (answered on 2026-10-19; it replaces the decision checkpoint of the first planning pass). The real sample fits in one batch at the limit chosen in Plan 04-06, so this matters only above that limit; split from Plan 04-14 to keep each plan under the per-plan file budget.
Output: the pending context target, the composed bodies of later batches, apply-time resolution of pending targets, and the batches-line sentence of the dialog.
</objective>
