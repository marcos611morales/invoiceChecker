</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-26 | Tampering | Report rows, toasts and tooltips rendering file names, issuer names and RFCs | high | mitigate | React text nodes only; acceptance grep forbids raw-HTML APIs in `src/features` |
