| Boundary | Description |
|----------|-------------|
| Dropped or picked files to the page | Arbitrary names and contents enter the UI |
| In-memory store to the next user of the same browser | Shared office computers; logout must not leave data behind |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-27 | Information disclosure | Logout leaving invoices in memory | medium | mitigate | `clearAll()` runs before `logout()`, which then performs a hard navigation that discards the JS heap; guards test asserts the order |
| T-01-28 | Tampering | Browser opening a dropped XML in the tab during processing | low | mitigate | dropzone root covers the window; react-dropzone still prevents default on document drops while disabled |
| T-01-29 | Denial of service | Accidental loss of loaded invoices (reload, logout) | low | mitigate | beforeunload while invoices are loaded (D-07b) and logout confirmation (D-07a) |
| T-01-SC | Tampering | npm/pnpm installs | high | mitigate | this plan installs nothing; `out=$(git log -F --grep="(01-13)" --format=%s -- package.json pnpm-lock.yaml) && test -z "$out"` holds at the end |
</threat_model>
