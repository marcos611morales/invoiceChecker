## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local files to the browser tab | File contents are read only in memory |
| Browser tab to the network | Nothing from the ingest path may cross it |
| Async ingest to the store | A batch may finish after the user cleared the session |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-16 | Information disclosure | `ingest`, store, domain (XML content leaving the browser) | high | mitigate | no network APIs in these modules (acceptance grep over request APIs); CSP and Playwright zero-body proof in Plan 01-06 |
| T-01-17 | Information disclosure | `sessionStore` persisting invoices | high | mitigate | zustand `create` without middleware; acceptance grep for browser storage APIs in store/domain/ingest/upload |
| T-01-18 | Tampering | Stale batch after logout/"Quitar todas" | medium | mitigate | generation captured before ingest, compared in `applyBatch` and via `isCancelled`; store test for the stale case |
| T-01-19 | Tampering | Duplicate counting through UUID case differences | medium | mitigate | parser uppercases UUIDs; first-wins dedupe keyed on that value; test with lowercase vs uppercase copies |
| T-01-20 | Denial of service | Very large folders freezing the tab | low | accept | chunks of 25 with a macrotask yield keep the UI responsive; the 2 MB per-file cap bounds each read; real data parses in about 25 ms |
| T-01-SC | Tampering | npm/pnpm installs | high | mitigate | this plan installs nothing; `git diff --quiet HEAD -- pnpm-lock.yaml` holds at the end |
