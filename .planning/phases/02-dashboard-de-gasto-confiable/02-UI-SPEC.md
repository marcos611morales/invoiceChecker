## Spacing Scale

Same scale as Phase 1 (multiples of 4; Tailwind 1 unit = 4px):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Icon-to-text gap, gap between value and delta line, badge inner padding |
| sm | 8px | Gap between filter controls, between chips, between badges, table cell vertical padding |
| md | 16px | KPI card padding, gap between KPI cards, gap between chart/ranking blocks, popover inner padding |
| lg | 24px | Chart card padding, page horizontal padding, gap inside a section |
| xl | 32px | Gap between dashboard blocks (filters, KPIs, charts, table) and between tabs and content |
| 2xl | 48px | Empty-state vertical padding |
| 3xl | 64px | Page bottom padding |

Exceptions (all multiples of 4, outside the 7-step scale on purpose):

- Everything listed as an exception in Phase 1 stays (top bar 56px, `max-w-6xl` 1152px, table rows 40px, 44px touch targets under 640px, 320px max list height).
- Mobile IVA sub-bar (under 640px only): height 52px, sticky directly under the 56px top bar (`top-14`). [user-confirmed, decision 4]
- Tabs list height: 40px.
- Trend chart plot height: 288px (`h-72`), overriding the `aspect-video` default of `ChartContainer` (use `aspect-auto h-72`).
- Supplier ranking row: min height 68px (name/amount line, 4px bar, caption line, 8px vertical padding).
- Filter option lists: max height 288px, inside the popover.
- Filter popovers: width 320px (Fechas, Forma de pago), 360px (Proveedor); full width of the trigger under 640px.
- Table expand column: 40px; actions column: 48px.
- "Ver todos" dialog: max width 720px; full-screen under 640px.
- Interactive controls: shadcn default heights (button 36px). Under 640px the filter triggers, the tabs, the IVA toggle items and the row "⋯" / chevron buttons grow to 44px [P1 touch-target rule].

## Typography

Exactly the Phase 1 set: **4 sizes and 2 weights**. Nothing new.

| Role | Size | Weight | Line Height | Used in this phase for |
|------|------|--------|-------------|------------------------|
| Body | 14px | 400; 600 for buttons, labels, tab triggers, KPI labels, ranking names/amounts, table headers | 1.5 | Table cells, filter triggers, tab triggers, KPI labels, ranking names and amounts, toasts, dialog text |
| Label / caption | 12px | 400 (600 for table column headers) | 1.5 | KPI delta line and sub-labels, chart axis ticks and tooltips, ranking caption, mode caption, filter chips, badges, table notes, "Diferencia de redondeo" line, chart legend |
| Heading | 20px | 600 | 1.2 | Section titles ("Gasto por mes", "Gasto por proveedor", "Facturas", "Calidad de datos"), dialog title |
| Display | 28px | 600 | 1.2 | KPI values, Calidad de datos card counts |

Rules:

- All amounts, counts, percentages and dates use `tabular-nums`; amounts in tables are right-aligned.
- Amounts are never truncated or abbreviated in KPI values, tables or tooltips. Only chart **axis ticks** may use compact notation (`Intl.NumberFormat("es-MX", { notation: "compact" })`).
- Negative amounts use the true minus sign U+2212 followed by the currency symbol: `−$1,000.00` [D-26]. `Intl` returns a hyphen-minus, so replace a leading `-` with `−` in the one shared money formatter.
- Folios and UUID fragments render in Geist Mono at 12px/400.
- No other sizes or weights anywhere in the phase.

## Color

Phase 1 tokens are unchanged (see 01-UI-SPEC Color). 01-UI-SPEC says "No third semantic color is introduced in this phase"; that sentence was scoped to Phase 1, and this Phase 2 contract supersedes it by adding `--positive` [D-20, user-confirmed decision 2]. This phase adds **chart** and **positive** tokens to `globals.css`, both themes:

| Role | Light | Dark | Usage |
|------|-------|------|-------|
| Dominant (60%) `background` | `#FFFFFF` | `#0A0A0A` | Page, chart cards, table body, popovers, dialog [P1] |
| Secondary (30%) `secondary` / `card` | `#F5F5F5` | `#171717` | Top bar, IVA sub-bar, KPI cards, Calidad cards, table header row, row hover, expanded concept panel, tab list background [P1] |
| Border | `#E5E5E5` | `#262626` | Card, table, chart-card 1px borders, chart gridlines (at 50% opacity) [P1] |
| Muted foreground | `#525252` | `#A3A3A3` | Captions, axis ticks, attenuated rows ("No suma", "Excluida", "Sustituida"), "Sin datos del periodo anterior" [P1] |
| Accent (10%) `primary` | `#171717` | `#E5E5E5` | See reserved list [P1] |
| Destructive | `#E7000B` / fill `#E7000B` | `#FF6467` / fill `#DC2626` | Unchanged; this phase adds **no** new destructive use (Excluir is reversible) |
| NEW `--chart-1` (bars) | `#737373` | `#A3A3A3` | Bar fill of the monthly trend and the supplier ranking bars. Non-text graphic: needs 3:1. |
| NEW `--positive` | `#166534` | `#4ADE80` | Text and arrow of a KPI delta that **decreased** [D-20] |

Map `--chart-1` and `--positive` in the `@theme inline` block (`--color-chart-1`, `--color-positive`) like the other tokens. The shadcn `ChartContainer` config for the bar series is `{ gasto: { label: "Gasto", color: "var(--chart-1)" } }`.

Contrast checks (WCAG AA: 4.5:1 text, 3:1 non-text graphics). New pairs only; Phase 1 pairs still hold:

| Pair | Light | Dark |
|------|-------|------|
| `--chart-1` bars on `background` | 4.7:1 | 7.9:1 |
| `--chart-1` bars on `secondary` | 4.3:1 | 7.1:1 |
| `--positive` text on `secondary` (KPI cards) | 6.5:1 | 10.3:1 |
| `--positive` text on `background` | 7.1:1 | 11.4:1 |
| Accent highlight bar (`primary`) on `background` | 17.9:1 | 15.7:1 |

Rules:

- 60/30/10: the dashboard surface is `background`; KPI cards, the top/sub-bars, the table header and the expanded panel are `secondary`; accent stays small. Chart cards use `background` with a 1px border so bars sit on the dominant surface (4.7:1).
- **Decrease is green, increase is neutral** [D-20 + user-confirmed]: a KPI delta that went up is rendered in `foreground` (neutral) with an ArrowUp; one that went down in `--positive` with an ArrowDown. Red is **not** used for increases (the destructive token is reserved, and a rise in spend is not an error). [user-confirmed, decision 2]
- Color is never the only carrier of meaning: every delta has an arrow icon, a sign and a sentence ("subió" / "bajó" in `sr-only` text); every attenuated row has a text label; the active IVA mode has a check icon, border and the mode caption.

Accent reserved for (Phase 1 list stays, item 6 is new; and nothing else):

1. Primary buttons: "Entrar", "Seleccionar archivos", "Agregar facturas".
2. Dropzone drag-over state and the window-wide drop overlay border.
3. Progress bar fill.
4. The active sort icon (ArrowUp/ArrowDown) in any table header.
5. The 2px keyboard focus ring on all focusable elements.
6. **New:** the 2px underline of the active tab, and the single bar under the pointer or keyboard focus in the monthly chart (hover/focus highlight; all other bars stay `--chart-1`).
Explicitly **not** accent: KPI numerals, filter chips, badges, links, the IVA toggle and the ranking bars. "Agregar facturas" remains the only accent-filled button on screen. [user-confirmed, decision 7]

Positive reserved for: the arrow, sign and percentage of a KPI delta that decreased. Nothing else.

### Destructive confirmations

None added. "Excluir factura" is reversible, applies instantly with no confirmation or reason, and offers "Deshacer exclusión" in the toast [D-29]. The exclusion lasts only the session [D-30]; nothing is written to `localStorage`. Phase 1's "Cerrar sesión" and "Quitar todas" dialogs are unchanged and now live: "Quitar todas" sits in the Importación tab header.

### Errors

No new error surfaces: all computation is synchronous and in the browser. If persisted settings are invalid or storage is blocked, the IVA mode silently falls back to "Con IVA" and the app keeps working (no message). Unexpected whole-import failure copy is unchanged [P1].

1. Date shortcuts ("Este año", "Últimos 3 meses") anchor on the last month with loaded invoices, not on today's date.
2. KPI deltas: a decrease uses the new green `--positive` token; an increase is neutral (foreground) with an up arrow.
3. The supplier ranking is an HTML list with proportional bars, not a Recharts chart.
4. IVA control on phones: a sticky 52px sub-bar under 640px, plus icon-only "Agregar facturas" and "Cerrar sesión" under 768px.
5. "Ver todos" opens a centered Dialog, full screen on phones.
6. "Ver factura" when filters hide the invoice: the filters stay untouched and an Alert with a "Quitar filtros" button appears.
7. Active IVA mode: a surface segment with border, bold text and a check icon (not accent-filled).
8. UI Considerations: the probe's proposed resolutions are accepted as a set (explicit where the contract answers, backstop for visual edge cases, dismissed with reason where a state cannot occur).
9. Truncated text on touch devices: a tap opens the full text in a Popover; pointer devices keep the Tooltip.
10. More specific copy: "Limpiar proveedores" / "Limpiar formas de pago", "Deshacer exclusión", and the no-match messages with the search text and "Revisa la búsqueda.". "Cerrar" stays.
11. Default date range: every finished batch that adds invoices resets the range to the full loaded span, even if the user had changed it.
