## Phase Goal

**As a** dueño, socio o contador del Coworking Café, **I want to** ver en qué se gasta y cuánto en promedio con montos que respetan las reglas acordadas (I/E/P, facturas en $0, excluidas), **so that** puedo confiar en las cifras sin revisar cada factura a mano.

<objective>
Close UAT gap G-02-10 (02-REVIEW.md WR-01): undoing or re-including a plain manual exclusion must never write `restored`, the D-28/D-42 set that means "the user overrode a TipoRelacion-04 substitution". Split the two meanings in the session store: an exact undo token for "Deshacer exclusión" (D-29) and a required `overrideSubstitution` option for "Volver a incluir", computed by each caller from `entry.substitutedBy` at click time. Apply the locked user decision: a row that is both manually excluded and substituted overrides the substitution when re-included.

Purpose: REGLA-08 (an exclusion and its undo must not change what counts later), CAL-01 (Sustituidas and Sustituciones in Calidad stay truthful). Without this, a later batch with a substitute silently double-counts the original (Gasto $232.00 instead of $116.00) and nothing alerts.
Output: new store contract (`ExclusionUndo`, `ReincludeOptions`, `undoExclusion`), the three UI callers rewired, the bug-locking tests inverted, regression tests per path, and the 02-06-PLAN truth line corrected.
</objective>
