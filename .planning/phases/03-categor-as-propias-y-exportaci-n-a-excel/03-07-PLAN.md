## Phase Goal

**As a** dueño, socio o contador del Coworking Café, **I want to** organizar el gasto en mis propias categorías (por proveedor y por concepto), que persisten en el navegador y se pueden respaldar, **so that** veo "en qué gastamos más" por categoría y me llevo el análisis filtrado a un Excel de varias hojas.

<objective>
Let the user download all their settings to a JSON file and restore them from such a file in any browser, replacing the current settings only after confirming, and rejecting any invalid file without touching anything.

Purpose: AJUS-02 and ROADMAP criterion 2, with D-07, D-08 and D-30, the format chosen in Plan 03-01 Task 2, and the replace-dialog and Alert UI considerations (E3, E4).
Output: the version-1 file contract with a golden fixture, `replaceAll`, a shared `downloadBlob`, `BackupControls` and `BackupErrorAlert` in the Categorías tab.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User-chosen file to the settings store | Any file from disk is untrusted: size, encoding, JSON shape and references |
| Settings to a file on disk | The downloaded file leaves the app and may be shared |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-15 | Tampering | Malicious or corrupted settings file (wrong shape, dangling ids, reserved names, "__proto__" keys) | high | mitigate | header check, newer-version check, frozen version-1 schema with D-30 limits and the integrity check, lists not records, nothing applied before an explicit confirm; tests per reason |
| T-03-16 | Denial of service | Oversized file read into memory or parsed | medium | mitigate | `checkBackupSize` on `file.size` before `file.text()`; 1 MB limit; test asserts text() is not called |
| T-03-17 | Tampering | Accidental replacement of good settings | medium | mitigate | AlertDialog with summary of the file, default focus on «Conservar los míos», destructive confirm last |
| T-03-18 | Information disclosure | Invoice data leaking into the settings file or a network request during download/upload | high | mitigate | `buildBackupText` writes only the four settings fields plus app and version (test asserts the key sets); acceptance grep forbids request APIs in the settings code |
</threat_model>
