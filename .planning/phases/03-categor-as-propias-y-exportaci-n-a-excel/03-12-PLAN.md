## Phase Goal

**As a** dueño, socio o contador del Coworking Café, **I want to** organizar el gasto en mis propias categorías (por proveedor y por concepto), que persisten en el navegador y se pueden respaldar, **so that** veo "en qué gastamos más" por categoría y me llevo el análisis filtrado a un Excel de varias hojas.

<objective>
Build the library-independent workbook model the export writes: cells with exact decimal strings and UTC dates, the first sheet «Resumen por mes» read from the Dashboard's own view, the workbook context and the D-19 file name.

Purpose: XLS-01/02/03 foundations with D-19 and D-23; Plan 03-13 installs the library, writes the file and adds the «Exportar a Excel» button that uses this model.
Output: `cellModel.ts`, `monthlyCounts`, `buildResumenMes`, `WorkbookContext`/`buildWorkbook`/`amountHeader`, `exportFileName`, and the export copy.
</objective>
