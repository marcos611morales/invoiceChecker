## Phase Goal

**As a** dueño, socio o contador del Coworking Café, **I want to** organizar el gasto en mis propias categorías (por proveedor y por concepto), que persisten en el navegador y se pueden respaldar, **so that** veo "en qué gastamos más" por categoría y me llevo el análisis filtrado a un Excel de varias hojas.

<objective>
Ship the export path end to end: the «Exportar a Excel» button in the top bar builds, from the Dashboard's own view, a workbook (first sheet: «Resumen por mes»), writes it with write-excel-file 4.1.1 under a CSP that lets its worker run, and downloads it with the D-19 file name.

Purpose: XLS-01/02/03 foundations with D-19, D-24, D-29 and every E8 UI consideration, plus the XLS-01 concurrency edge.
Output: the approved package installed, the CSP change, the cell model, the library mapper, the writer with timeout, «Resumen por mes», the file name and the export button.
</objective>
