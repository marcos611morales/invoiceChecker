## Phase Goal

**As a** dueño, socio o contador del Coworking Café, **I want to** ver para cada producto agrupado en qué tienda me sale más barato, cuánto podría ahorrar y cómo ha cambiado su precio en el tiempo, comparando solo cantidades comparables, **so that** sepamos dónde nos conviene comprar cada producto sin subir los datos a ningún servidor.

<objective>
Let the user see and fix the content of each description inside the opened product (D-13, D-14): the «Contenido de cada descripción» section showing how each member's content was read, the missing-content notice, then the validated inline editor that saves or removes a correction with immediate recalculation (D-15, D-28).

Purpose: Plan 05-10 makes corrections count; this plan is where the user captures them, one edit per description, so unsized Walmart-style lines become real comparisons.
Output: `ContentTable.tsx`, `ContentEditor.tsx`, the panel wiring and notice, `formatCorrection`, copy and tests.
</objective>
