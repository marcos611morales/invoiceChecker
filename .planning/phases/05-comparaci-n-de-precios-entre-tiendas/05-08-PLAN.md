## Phase Goal

**As a** dueño, socio o contador del Coworking Café, **I want to** ver para cada producto agrupado en qué tienda me sale más barato, cuánto podría ahorrar y cómo ha cambiado su precio en el tiempo, comparando solo cantidades comparables, **so that** sepamos dónde nos conviene comprar cada producto sin subir los datos a ningún servidor.

<objective>
Let the user fix or capture the content of each description inside the opened product (D-13, D-14): show how each member's content was read, edit it with a validated inline editor, persist it per member (D-15), and recompute the comparison at once; a typed piece count counts as a verified size (D-28).

Purpose: on the real sample most Walmart descriptions carry no size (RESEARCH Pitfall 7), so without this editor most cross-store comparisons stay «no normalizado». This plan turns them into real comparisons with one edit per description.
Output: correction reducers and store actions, content precedence with corrections, per-member content rows, `ContentTable.tsx`, `ContentEditor.tsx`, the missing-content notice, copy and tests.
</objective>
